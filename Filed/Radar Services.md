	2. ATC instructions
		1. "Ident" (press the ident key, no need to verbally respond "ident")
		2. "Squawk VFR" (press 1200 or the VFR key)
		3. "Squawk standby" (switch from ALT mode to STBY), then "squawk normal" (switch back to ALT)
		4. "Reset transponder" (confirm the code and ALT mode; if that doesn't work, consider turning the transponder off/on again)
		5. "Stop altitude squawk" (switch to ON instead of ALT)
